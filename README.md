# 电脑红外遥控器

通过电脑 USB 控制机顶盒等红外设备。
硬件: IR03T 红外学习模块 + CH340 USB转TTL + 杜邦线 (免焊)

## 硬件接线

    IR03T        USB转TTL
    VCC    ---   5V
    GND    ---   GND
    TXD    ---   RXD
    RXD    ---   TXD

注意: TXD 接 RXD, RXD 接 TXD (交叉连接)

## 安装依赖

    pip install pyserial

## 启动

    python ir_remote.py

或双击 run.bat

## 使用步骤

1. 连接硬件, 插入电脑 USB
2. 打开软件, 选择串口 (如 COM3), 点击 连接
3. 点击 新建, 创建遥控器 (如 芒果TV 机顶盒)
4. 点击 学习按键, 输入按键名, 按提示学习
5. 学习完成后, 点击按键即可发射红外信号

## 长按连发

按住按键不松开：立即发射一次，400ms 后每 180ms 连续发射，松开停止。
适合音量+ / 音量- / 频道+ / 频道- 这类需要连发的按键。

## 串口协议 (IR03T)

    帧格式: FA FD <命令> <数据> DF
    学习:   FA FD 01 xx DF  -> 反馈 A1 (进入学习), A2 (学习完成)
    发射:   FA FD 02 xx DF  -> 反馈 F1 (发射完成)
    xx = 通道号 00~FF

## 常见问题

连接失败:
- 检查 USB转TTL 驱动是否安装 (CH340 驱动)
- 检查串口是否被占用

学习失败:
- 检查红外接收头是否对准原遥控器 (距离 20cm 内)
- 检查波特率是否正确 (默认 9600)
- 检查接线是否正确 (TXD 接 RXD)

发射无反应:
- 检查红外发射管是否对准机顶盒
- 检查距离是否太远 (建议 1~3 米)
- 检查机顶盒是否支持红外 (蓝牙遥控器除外)
